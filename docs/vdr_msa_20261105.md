# VDR：2026-11-05 AF3 MSA 更新

VDR 新输入采用用户提供的最新 AF3 结果。查询仍为既定 259 aa 构建体，
H305F（构建体第 137 位 F）和 Δ165–215 保留，口袋映射和初始配体不变。

| 资源 | 含查询的记录数 | SHA-256 |
|---|---:|---|
| unpaired.a3m | 7,649 | `a6496853bc118ac4cd0289b704fda13d52c847433f7a232e31e1deeb4149c59d` |
| paired.a3m | 43,886 | `7a2a71067b8df0f64531cd8c225f5746d25834c8c63c099cd4fc2a3b5b14295d` |
| 完整十一靶点数据包 | 209 项归档记录 | `100596066de4782c7a3cb95c432a55a7c5bec4bc2467e069eb0e946f9252d5ab` |

所有 A3M 行去除小写插入字符后均为 259 列。Server JSON 内嵌 unpaired MSA
与独立 A3M 文件逐字节一致。源数据包、原始 AF3 来源记录、两份 A3M 均完整保存。
单蛋白链 MolCraft 输入使用 unpaired 文件；paired 文件留作 AF3 数据来源，
不把它解释成当前单体设计的跨蛋白配对约束。

VDR 的 `prepare-example` 已固定这次来源，直接保存完整 unpaired 输入，不在导入
阶段裁剪到 1,024 行。旧 GBA 导入方式保留。优化入口验证完整文件的查询、列宽、
SHA-256 和来源凭据；不再把模型内部 MSA 预算当作文件记录数上限。
原始文件包含一个模糊残基 Z，保留原字节；Boltz 原生解析器将 B/Z/J/O/U 映射到 UNK。

模型内部设置仍为 `subsample_msa=True, num_subsampled_msa=1024`，原生解析还会按其
规则去重。因此“输入文件 7,649 条”不等于“每次模型计算同时使用 7,649 条”。
亲和力嵌入继续使用原生 query-only profile。实际原生解析条数和输入形状应结合
导入校验报告与后续 `feature_profile.json` 读取。

远端共享输入位置：


此前单序列 VDR 配置更新为 `run.msa_mode: provided`，并指向该 unpaired 输入。
原配置在更新目录备份，历史检查点、梯度、预测和实验结构保留。修改 MSA 会改变
运行身份，后续任务使用新输出目录，不在旧单序列检查点上继续。

重新生成 de novo 对照配置时可显式覆盖旧 VDR 单序列来源：

```bash
python scripts/prepare_denovo_run.py \
  --gba-config outputs/syncraft-v2-fixed-rounds-20261105/configs/GBA.yaml \
  --vdr-config outputs/syncraft-v2-fixed-rounds-20261105/configs/VDR.yaml \
  --vdr-msa outputs/vdr-msa-20261105/input/input.a3m \
  --evidence-manifest data/inventory/uspto_simpretro.sqlite.manifest.json \
  --output outputs/denovo-msa-20261105/configs
```

生成配置保留 GBA 17 轮、VDR 16 轮，每轮最多 8 次候选复评。
