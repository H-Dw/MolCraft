# 梯度策略、原子更新与三套运行配置

本次核对基线为 MolCraft `9ff82a2`、Mosaic
`5937f37164bcb28bc6f1000f10134145438e5971`、DBMol arXiv:2607.19237v1。
用户所写 BDMol 在本文按此前讨论的 **DBMol** 理解，配置文件保留请求的
`bdmol-like.yaml` 命名。本次新增配置和单轮批量复评分入口，梯度核心与合法编辑
算法保持不变。

建议以 **mosaic-like 作为正式服务的候选预设**：保留直接坐标损失反传，采用独立
预测深度复评分，并约束亲和力代理项不恶化。test 用于回归；bdmol-like 用于截断
结构反向、去掉直接几何目标的对照。新的 200 步／4-pass／8 候选组合尚未进行
真实模型 GPU 验收，不能称为已验证的生产配置。

## 1. 当前回传与更新策略

当前分子始终为合法离散图 G，重原子数 N 固定。构造
`A[N,9]` 元素 one-hot、`B[N(N−1)/2,5]` 无向键 one-hot、`c[N]` 标量形式电荷。
冻结结构与亲和力模型，对当前 one-hot 点计算 `∂L/∂A, ∂L/∂B, ∂L/∂c`。
这些浮点张量提供导数接口，计算后不执行多步连续分子图优化。

- A 映射到 Boltz 原子序数列，C 为 6，N 为 7。蛋白特征固定。
- B 映射到完整原生键词表，以 `B_native @ embedding.weight` 代替整数查表；
  无键为 0、单键为 2。连接指示同步为 `1−B_NO_EDGE`。
- 每个无向原子对只有一组变量，两个方向共享变量，因此反向梯度自动合并。
- c 写入原生 `ref_charge`。连续导数用于评价离散 −1、0、+1 方向。
- 当前参考坐标、原子名称、预处理、离散框架选择都不是可微优化变量。
  实际替换之后重新构建这些派生特征。

### 目标与有效梯度路径

默认目标为

\[
L=L_{aff}+2.5L_{contact}+2.5L_{conf}+L_{geom}.
\]

`L_aff = affinity_pred_value − affinity_logits_binary`。多头概率平均后取 logit，
回归值取均值，关闭分子量校正。这里是透明实现的代理目标，不是物理结合自由能。

接触项为口袋残基与配体 token 的 distogram 在 `<8 Å` 内的概率质量的负对数。
每个口袋残基取最强配体接触，再与全局最强锚定接触等权平均。

`L_conf = −ligand_ipTM −0.3 ipLDDT +0.3 ipDE +0.1 PDE
−0.3 confidence_score −0.1 pTM`，使用代码定义的配体／界面掩码和置信度实现。
这不保证与未披露的 DBMol 代码逐输出一致。

`L_geom` 使用原始原子坐标：对每个口袋残基与配体的原子距离做温度 0.5 的
softmin，再施加 `softplus(distance−6 Å)`；另加范德华重叠平方惩罚，重叠尺度 0.75。
不经过蛋白 backbone 或 atom37 视图。

| 目标 | 有效回传路径 | 当前边界 |
|---|---|---|
| 接触 | distogram → trunk → 配体输入 | 不需要穿过坐标扩散 |
| 亲和力 | affinity 输入嵌入／heads、结构 trunk pair → 配体输入 | 原生坐标硬分箱不给平滑坐标导数 |
| 置信度 | confidence heads、输入与 trunk → 配体输入 | 距离硬分箱、框架选择／有效性掩码保持离散 |
| 直接几何 | 实际坐标 → 扩散采样器 → 条件与 trunk → 配体输入 | `through_structure` 保留这条路径 |

`through_structure` 不表示所有几何操作都可微。recycling 历史 state 被截断，
采样器使用的刚体拟合变换是否截断沿用原生采样策略；最近邻、分箱、布尔掩码等
仍有离散边界。`trunk_only` 在采样后对坐标 stop-gradient，要求几何权重为 0；
**结构模块仍执行前向**，以生成置信度／亲和力需要的坐标。

### 从导数到“换成什么”的概率

当前元素为 aᵢ，替换为 k 的一阶方向分数为

\[
\Delta_{i,k}=g_{A,i,k}-g_{A,i,a_i},\qquad
q_i(k)=\frac{M_i(k)\rho_i(k)e^{-\Delta_{i,k}/\tau}}
{\sum_l M_i(l)\rho_i(l)e^{-\Delta_{i,l}/\tau}}.
\]

负方向分数表示预计降低损失。默认温度 τ=1、先验 ρ 均匀，保留不修改选项。
键使用类别梯度差；电荷方向使用 `g_c,i × (c′−cᵢ)`。概率是当前局部梯度诱导的
偏好，既不是实验成功率，也不是模型校准的分子后验。

实际更新按以下顺序执行：

1. 对每个原子／键／电荷方向计算分数，并检查单项编辑，生成合法性掩码与原因。
2. 每通道保留至多 32 个低分原始方向。单项非法方向仍可参与联合组合，例如
   四配位 C→N 必须与电荷 +1 配合；不会因单项掩码为零而提前丢弃所有协同机会。
3. 枚举单项和两项联合操作。当前两项操作必须相容并共享至少一个原子，不能一次
   修改两个互不相邻的原子类型。联合分数是一阶方向分数之和，没有二阶交互项。
4. 对整个操作包应用 RDKit 严格检查，核对价态、连通性、稳定 ID、立体信息等，
   去除重复图；在保留下来的合法候选集合及 NO_OP 上独立归一化概率。
5. 选择若干候选，重建实际原生化学特征、参考构象、电荷和映射，再进行真实模型
   复评分。禁止逐原子独立采样后一次性覆盖整张图。
6. 由调用方接受具体 `candidate.graph`，作为下一轮的离散 G。下一轮重新 one-hot
   并重新求导。A/B/c 的梯度和旧提议不能跨源图指纹直接复用。

当前并非完全避免构造非法试探图：CPU 化学检查会构造并拒绝非法 proposal。
保证的是不把这些图提交给 Boltz，也不把它们认定为新的当前分子。

温度调整概率尖锐程度，但在均匀先验、确定性按概率排序时不改变候选排序。
当前没有通过改变温度实现随机探索。`frozen_atom_ids` 会冻结涉及这些原子的全部
元素、电荷和键操作；没有 LLM 服务，Agent 协议仅选择已验证候选 ID。

### 实际更新示例

已验收的 25 步运行中，源图为 `[CH3:1][CH2:2][CH3:3]`。候选 1 同时进行
原子 3 的 C→P、键 2–3 的单→双，得到 `[CH3:1][CH:2]=[PH:3]`。其一阶预测变化
为 −1.223809，真实复评分变化为 −0.781116，联合损失从 8.010627 到 7.229510。
环状候选和电荷候选却分别使损失上升，证明需要实际复评分。

该候选的亲和力分项从 3.601887 升至 5.064646，联合下降来自其他项补偿。以这些
25 步分数判断时，新的亲和力不恶化门控会拒绝这个候选；200 步下的结论要重新测量。
这个含磷小分子仅用于接口验收，不是有实验结合证据的设计结果。

## 2. 与 Mosaic、DBMol 的逐项差异

| 维度 | MolCraft | Mosaic，固定提交的 Boltz-2 路径 | DBMol，arXiv v1 |
|---|---|---|---|
| 优化对象 | 原子元素、无向键、形式电荷 | 主要为 20 类氨基酸 PSSM；也有离散序列优化器 | 原子／键连续类别向量、连续电荷 |
| 输入反馈位置 | ref_element、连续键嵌入与连接指示、ref_charge | res_type、MSA query、profile | 对配体三类原生化学输入作可微松弛 |
| 当前迭代状态 | 合法离散图，one-hot 点局部求导 | APGM 可持续维护软 PSSM，再锐化／离散化 | 持续维护软分子图，类别 clip 后行归一化 |
| 更新算子 | 梯度差分 → 小联合编辑 → 全图检查 → 真实评分 | simplex_APGM／batched APGM；另有 gradient_MCMC | SGD，50 步，学习率 2.0；随后采样并投影 |
| 与离散优化的关系 | 接近梯度辅助局部离散搜索 | gradient_MCMC 也会利用梯度提出离散突变 | 主流程为连续松弛优化后投影 |
| 几何反向 | 默认保留直接坐标几何通过结构扩散的反向 | 可微采样器支持自定义直接坐标损失 | 附录明确不穿过结构模块反向 |
| 目标 | DBMol 风格三项 + 直接几何 | 通用可组合损失，不存在唯一配方 | 亲和力 +2.5 接触 +2.5 置信度 |
| 化学合法性 | 提议包全图检查，非法图不进入真实评分 | 蛋白序列接口不承担任意配体图价态检查 | 松弛更新不保证合法，DeFoG 投影后仍过滤非法样本 |
| 分子先验 | 当前主要是合法规则、局部编辑和可配置先验 | 可组合 ProteinMPNN、语言模型、稳定性等先验 | DeFoG 提供学得的分子图先验；可选 SynFormer |
| 搜索范围 | 固定重原子数、最多两项共享原子操作，局部 | 蛋白序列可连续变动多个位置 | 软图优化和 learned projection 可作更广图变化 |
| 几何读取 | 原始模型原子轴及稳定 ID 映射 | 通用 backbone、atom37 视图含标准蛋白假设 | 配体图与结构预测接口 |
| 候选选择 | 有限合法池按方向偏好提出，再真实复评分 | 依使用的连续／离散优化器及自定义 pipeline | 投影生成 2048 个，过滤后随机取 100 个，不按评价分数后选 |
| 新增服务门控 | 批量复评分可要求联合下降且代理亲和力项不恶化 | 非统一框架默认设置 | 不是其论文默认生成／评价筛选流程 |

结构模块截断不等于“梯度没有周围原子信息”：trunk 的交互表征已经包含上下文。
分子非法性的核心是类别、键和电荷的组合约束不被连续松弛／独立离散化保证。
即使保留结构反向，也不能代替价态与图合法性检查。这是对计算路径和约束的分析，
不是论文额外给出的实验结论。

## 3. 预算的准确含义

旧版默认已经是：每通道 32 个原始方向、最多检查 256 个联合包、最多保留 32 个
不同合法编辑图，再加一个 NO_OP。上次 GPU 验收的 `--candidate-budget 2` 只复评
其中两个，不代表只生成两个。它是一轮化学提议，不是 25 轮分子优化。

`max_proposals=256` 仅限制后段联合包检查；前面还会检查所有未冻结的单项方向。
在无冻结、无额外限制时约为 `8N+4N(N−1)/2+2N = 2N²+8N` 次单项试探，不能
把总化学检查成本说成恒定 256 次。
去重依据带稳定 ID 的图指纹，不保证移除 atom-map 后仍是 32 种独特化合物；
正式化合物库的去重还需另行检查规范化的无映射化学结构。

DBMol 的几个数量属于不同层级：50 次是松弛分子优化；200 步是 DeFoG 去噪，
起始 t=0.8；2048 是投影采样批量，100 是过滤后随机保留的评价分子数。
不能把 2048 解释为每次 Boltz 梯度后都调用 Boltz 复评 2048 个候选。
核查的正文／附录没有明确给出可直接采用的 Boltz 结构扩散步数，因此没有把
DeFoG 的 200 步冒认为 Boltz 推理步数。

Mosaic 的固定 Boltz-2 实现明确区分设计 25 步／1 个 trunk pass，独立预测
200 步／4 个 trunk pass。这里 pass 指总 trunk 次数；4 次对应原生 Boltz CLI
的 3 次额外 recycling，不能再多加一次。其他模型或 notebook 可以自行覆盖参数。

## 4. 三套可加载配置

三份 YAML 共用人工 12 aa／CCC 输入以便控制比较。**实际任务必须更换蛋白、口袋、
配体及资源路径**。CCC 只有三个重原子，算法不会自动把它扩增成药物大小。
N 由初始 SMILES 确定；如使用全碳链起点，也需先确定所需重原子数。

| 参数 | test.yaml | mosaic-like.yaml | bdmol-like.yaml |
|---|---:|---:|---:|
| 梯度模式 | through_structure | through_structure | trunk_only |
| 亲和力／接触／置信度／几何权重 | 1 / 2.5 / 2.5 / 1 | 1 / 2.5 / 2.5 / 1 | 1 / 2.5 / 2.5 / 0 |
| 梯度阶段扩散步数 | 25 | 25 | 25，工程选择 |
| 梯度阶段 trunk pass | 1 | 1 | 1，单次 pass 的本项目定义 |
| 每通道原始方向上限 | 32 | 32 | 32 |
| 联合包检查上限 | 256 | 256 | 256 |
| 合法编辑候选上限 | 32 + NO_OP | 32 + NO_OP | 32 + NO_OP |
| 每次批量复评分的编辑候选上限 | 2 | 8 | 8 |
| 复评分扩散步数 | 25 | 200 | 200，来自共同复评分策略 |
| 复评分 trunk pass | 1 | 4 | 4，来自共同复评分策略 |
| 温度／先验 | 1 / 均匀 | 1 / 均匀 | 1 / 均匀 |
| 每图坐标噪声样本数 | 1，seed=0 | 1，seed=0 | 1，seed=0 |
| 单候选编辑数 | 1–2，共享原子 | 同左 | 同左 |
| 新增亲和力不恶化门控 | 关闭 | 开启 | 开启 |
| 一次调用的外层化学轮数 | 1 | 1 | 1 |

三套均保持元素 `{C,N,O,F,P,S,Cl,Br,I}`、键 `{NO_EDGE,SINGLE,DOUBLE,TRIPLE,AROMATIC}`、
电荷 `{−1,0,+1}`。没有设置连续图 SGD 学习率；温度 1 不是 DBMol 学习率 2 的改名。
bdmol-like 只借鉴目标和结构反向截断，仍使用 MolCraft 合法离散提议，没有引入
50 步连续优化或 DeFoG。Mosaic-like 也没有把小分子更新改成蛋白 PSSM/APGM。

保持两套正式候选预设的化学预算与共同复评分深度相同，便于比较；两者优化目标
仍不同，不能只比较各自的总损失数值，应比较共同的分项和独立评价指标。

### 配置现在如何生效

```bash
# 编辑配置中的实际 target / pocket / ligand / model_paths 后运行。
molcraft propose --config configs/mosaic-like.yaml --output outputs/proposals
molcraft evaluate-set --config configs/mosaic-like.yaml \
  --packet outputs/proposals/proposals.json --output outputs/evaluation
```

`run.sampling_steps/trunk_passes` 用于梯度设计；新 `evaluation` 节控制真实复评分
深度、预算和亲和力门控。旧配置没有该节时，保持原深度和默认预算 2。
单候选 `molcraft evaluate` 也使用复评分深度；批量预算由 `evaluate-set` 实施。

每轮批量复评分重新计算源分子的同深度基线，随后对最多 B 个编辑图使用同一组
按稳定 ID 重排的随机量评分，因此预算为 `1 次源分子 + 至多 B 次候选`。例如
mosaic-like 至多 9 次 200 步前向；另外还需一次 25 步的梯度前向／反向。
这与诊断脚本额外运行四个分项反传的次数不同。

`evaluate-set` 在实际结果中选择联合损失低于基线、且满足启用的亲和力门控的图。
没有合格改善时返回 `source_retained` 和 NO_OP。`evaluation.json` 保留所有实测
分项，`next_graph.json` 保存建议的完整下一状态；不修改用户的原输入。
下一轮须保留整个图对象和 hydrogen_policy，不只复制 SMILES。
当前还没有自动多轮提交、训练或 LLM Agent 服务。

现有 `scripts/test_model.py` 是诊断程序，按 `run` 深度统一检查梯度、源分数重放和
候选，且其 `--candidate-budget` 是独立诊断参数。200 步复评分预设应通过上述
生产接口验证，不能把诊断脚本的通过记录冒称为新复评分深度已通过。

## 5. 正式服务的选择与验收边界

优先选择 mosaic-like 作为待验证基线，原因是：本项目的直接几何反向已在真实
25 步运行得到证据；正式输出以独立原生预测深度复核；候选预算有界；源分子保留
可作为不改善时的返回状态；亲和力代理项不再被其他项的改善掩盖。

bdmol-like 适合研究对照，也适合作为较大体系中结构反向显存受限时的候选策略。
截断只减少结构反向负担，结构前向依旧存在。去掉直接几何优化后，实际位姿与
口袋几何仍需独立检查，不能把 distogram 接触改善等同于坐标接触已改善。

本次 CPU 检查覆盖：三套配置、旧配置兼容、不同设计／复评深度、候选预算、
按实测分数重新排序、亲和力门控、NO_OP、过期图拒绝、非有限分数失败及 CLI
写出下一图。官方 JAX 0.12 CPU 为 **81 passed，1 deselected**（13.29 s），
官方 JAX 0.6 CPU 同为 **81 passed，1 deselected**（13.01 s）；Ruff 和 wheel 构建通过。
没有新运行模型权重／GPU。新的 8 候选、200 步、4-pass 和门控组合
需在实际目标尺寸上验证显存、延迟和筛选收益。此前的真实 GPU 证据只覆盖
25 步／1-pass、小型人工复合物及固定预算，不是生产负载或结合活性结论。

当前单轮 CLI 是上线组件，不是完整线上系统：尚缺自动多轮状态驱动和真实目标
验收。提议包当前主要绑定源图指纹，正式任务还应绑定蛋白、口袋和权重上下文。
本文没有把三份示例配置等同于这些能力已经实现。
